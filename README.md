# Web Development Foundations

A hands-on learning repository for junior developers to understand basic web development, practice coding skills, and build good development habits.

## What this repository is for

The tutorials and exercises will introduce how websites and web applications work, from the browser interface to the backend. Topics will include:

- Structuring pages with HTML and styling them with CSS.
- Adding browser interactions with JavaScript.
- Understanding HTTP, requests, responses, and client-server communication.
- Building backend functionality using Python.
- Practicing readable code, debugging, testing, and version control.

Python is the language used for backend examples. The focus is on web development concepts and coding best practices.

## Repository organization

The `main` branch contains only this README, which explains the repository's purpose. Tutorials, exercises, and example code will live on separate branches.

### Adding tutorials

Whenever a new tutorial is added, update this catalogue on `main` with its title, branch link, learning topics, and prerequisites. Keep `main` limited to this README and place lesson code and exercises on the tutorial's branch.

## Learning approach

Learn a concept, try a small example, complete an exercise, and reflect on how to make the solution clearer and more reliable.
